STEP 0 · DATABASE

PostgreSQL 비밀번호 설정

추천 비밀번호를 그대로 쓰거나 직접 입력하세요. 저장하면 필요한 서비스를 자동으로 설치합니다. 콘솔 로그인 비밀번호는 다음 단계에서 따로 설정해요.

다운로드 파일에는 비밀번호가 포함됩니다. 비밀번호 관리자나 안전한 곳에 보관하세요. 설치 후에는 이 화면에서 다시 확인할 수 없어요.

인앱 이벤트 팝업 · 선택

로컬 설치는 기본값으로 테스트할 수 있어요. 외부 접속은 콘솔과 다른 HTTPS 호스트를 준비하고 이 서버의 127.0.0.1:연결 포트로 연결하세요.

업로드 파일은 NudgeOn 데이터 볼륨에 저장됩니다. DB와 인앱 파일 볼륨을 함께 백업하세요. 캠페인은 콘솔에서 검수·게시해야 노출됩니다.

      STEP 1 · CLAIM
      
        
      설치 소유권 확인
      
        
      이 서버를 띄운 사람만 첫 Owner를 만들 수 있도록, ./nudgeon up이 터미널에 보여준 설치 코드가 필요합니다.
          링크로 들어왔다면 자동으로 확인합니다. 코드를 잃었다면 ./nudgeon setup-url --token 또는 ./nudgeon setup-token rotate.

      SECURED
      
        
      설치가 완료됐어요
      
        
      Owner 계정과 워크스페이스·앱이 만들어졌고, 설치 코드는 폐기됐습니다. 아래 키는 지금 한 번만 표시됩니다. 분실하면 콘솔의 키 회전으로 새로 발급합니다.
      
        
      
        
      크리덴셜은 이 서버의 마스터키로 암호화됩니다. DB 백업만으로는 풀 수 없으니 서버에서 NUDGEON_RECOVERY_PASSPHRASE=… ./nudgeon secrets backup으로 복구 번들을 내보내 DB 백업과 다른 곳에 보관하세요. 위 fingerprint가 번들의 것과 같아야 합니다. ./nudgeon doctor가 백업 여부를 알려줍니다.
